### 🚀 Featured Projects

**🧾 Automated B2B RFP Response System** · *Agentic AI · NLP · Python*
End-to-end pipeline (3-person team) that automates RFP processing, PDF/OCR ingestion, spec extraction and semantic SKU matching, cutting proposal turnaround by **60–80%**. Combines rule-based compliance validation with LLM-driven proposal generation. I owned agent design and core business logic.

**📡 Indoor Vehicle Tracking System** · *ESP32 · C++ · BLE · IoT*
BLE indoor localization with RSSI outlier suppression and signal filtering, reducing mean positioning error by **40%** under multipath interference. Edge-to-cloud telemetry over Wi-Fi/HTTP with **200 ms** processing latency and **99%+** delivery reliability.

Concurrent server built on `ThreadPoolExecutor` with a bounded queue and `CallerRunsPolicy` backpressure. Load-tested with **10,000 concurrent virtual users** in Apache JMeter, analyzing throughput, latency and thread-pool saturation.
